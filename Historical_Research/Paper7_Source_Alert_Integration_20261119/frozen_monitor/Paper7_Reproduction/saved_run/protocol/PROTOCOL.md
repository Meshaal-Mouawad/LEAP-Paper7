## Contribution and endpoints
RQ1: Which current-context, policy-version, and observation/suppression binding fields are necessary for exact governance-episode decisions under the stated policy? RQ2: Do independently written online and retrospective reference implementations agree, and where do controlled removal of binding/freshness checks change decisions? RQ3: Are decisions invariant to metadata-only and equivalent time-unit transformations?

Primary computational endpoint: complete-trace agreement of the full (state, active, severity) sequence with the frozen independently written oracle. Secondary endpoints: event tuple agreement, active false negatives (reference active / output inactive), active false positives (reference inactive / output active), exact active-episode interval agreement, severity agreement, and reason agreement. Policy reason labels identify the violated input-contract condition; no empirical root-cause localization accuracy is claimed. UNKNOWN preserves previous active state. Count UNKNOWN explicitly. Report exceptions and unresolved inputs separately. Latency and operational harm are not endpoints. Policy-selected dwell/escalation times are timing conditions, not measured detection delays.

## Sample rationale and split
329 designs per family: exhaustive 4-observation alphabet sequences of length 4 (256); 3 long controls; 11 intervention types at each of 5 positions (55); five temporal boundaries at below/equal/above offsets (15). This is finite combinatorial coverage, not a power calculation or probability sample. Every design has a base, irrelevant metadata, and equivalent milliseconds variant. Five families yield 4,935 traces in 1,645 transformation groups. Privacy and dynamic-execution families are development; audit, transfer, lineage are held out. Each simulated artifact belongs to one family; all related variants stay together. Both source artifact and alarm family are disjoint across this split. They are synthetic source artifacts, not independently sampled industrial source systems. Temporal templates are deliberately shared across families: this is an adapter-transfer and conformance check, not unseen temporal-pattern generalization. All input templates are generated before freeze; held-out reference comparisons are not inspected until freeze.

## Methods
Bound: new incremental monitor with all specified checks. Reference: separately authored retrospective oracle, written by a separate AI agent from the specification without viewing Bound; 29 independently hand-calculated checks. It is the complete-contract executable comparator and reference, not independent human adjudication. Snapshot: recovered static finding values applied per event, for descriptive lifecycle mismatch only; no temporal requirement is retroactively imposed on legacy LEAP. Timer-only: full timer/freshness/conflict semantics but no version resets or observation/suppression binding. No-evidence-binding: full version resets and temporal policy, ignores observation c/p mismatch. No-suppression-binding: full policy except suppression c/p mismatch. No-freshness: full policy except stale-age rejection. All methods receive identical packets and policy; no external monitoring framework is claimed to have been run.

## Information necessity assay
For each of five families, construct six pairs of traces differing only in one field: event.c, event.p, o.c, o.p, s.c, s.p. The same field is removed when forming the input projection. Full-reference output must differ for a valid witness. For each projection equivalence class C and gold sequence y, let n(C,y) be its frequency. Every deterministic function of the projected complete input has at most sum_C max_y n(C,y) correct complete traces. Proof: its one output on C can match only one gold sequence. This is an information-loss upper bound, not a fitted performance estimate. It also upper-bounds causal monitors. Suppression witnesses target displayed state/severity, since their active state is unchanged. Independent review checks proof and witness interpretation. Assay is separate from held-out trace-performance denominators.
