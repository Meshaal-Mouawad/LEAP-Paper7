# Paper 7: version-bound governance review episodes — specification 1

Date: 2026-11-18. New research development. Existing LEAP produces stateless source-review warnings. The following lifecycle policy is an explicit experimental policy, not a recovered industrial operating requirement or a regulatory interpretation.

## Question and unit
Can evidence-context and policy-version binding prevent incorrect episode decisions when successive governance-review observations are missing, stale, conflicting, or refer to superseded contexts, while retaining ordinary temporal behavior? Primary unit: complete finite event trace for one (source artifact, rule family). Secondary: event state, alert-active episode intervals, transition reasons. A warranted alert means an active review episode under this specified policy. No physical safety or operational consequence endpoint.

## Input
Each event has strictly increasing time t in seconds (unit s) or milliseconds (unit ms), context string c (current relevant source-evidence context), policy string p, and optionally observation o = {value: true/false/null, c, p, at: timestamp in the event unit}. null means conflicting evidence. Missing o means missing evidence. Metadata is irrelevant. Policy object supplies dwell D=2 s, clear C=2 s, escalate E=4 s, freshness F=2 s. Thresholds inclusive. Context refers to a relevant evidence version, not arbitrary file formatting. Observation c and p must equal event c and p. Age must be 0 <= t-at <= F. Event source family and artifact are fixed per trace. Invalid unit/time/non-monotone time is an execution failure, not a silent no-alert.

Optional suppression s = {c,p,until}, in event time unit. Suppression is valid only if c,p match current context/policy and t<until. At exact expiration it stops. Suppression is an explicit synthetic authorized-review deferral input; it never changes underlying episode activation or escalation timing. No suppression learned from comments.

## Transition order
1. Normalize times. Validate strict increasing t. Initially active=false; positive_start, negative_start, opened_at unset; previous context/policy unset.
2. On any change to c or p after the first event, discard all three timers and active=false before processing this event. Record reset reason POLICY_CHANGE if p changed, otherwise CONTEXT_CHANGE. First event is not a reset.
3. Determine observation validity in precedence: missing -> MISSING; context mismatch -> CONTEXT_MISMATCH; policy mismatch -> POLICY_MISMATCH; future age -> FUTURE; age>F -> STALE; value null -> CONFLICT; otherwise valid. Missing/conflicting/invalid observations set both qualification timers unset; preserve an existing active episode and opened_at. Display UNKNOWN, even if active is retained. Suppression does not override UNKNOWN.
4. Valid true: reset negative_start. If inactive, initialize positive_start to t if unset, activate at first observed t-positive_start>=D; opened_at=t on activation. If already active retain opened_at. Valid false: reset positive_start; if active initialize negative_start=t if unset, clear at first observed t-negative_start>=C, removing opened_at and negative_start. If inactive clear negative_start.
5. Unsuppressed valid output: if active and t-opened_at>=E => ESCALATED; if active => ACTIVE; else if positive_start set => PENDING; otherwise CLEAR. Valid suppression overlays SUPPRESSED on ACTIVE or ESCALATED only. Internal active and opened_at retained. Escalation severity HIGH; ACTIVE severity base severity from recovered rule; otherwise NONE (UNKNOWN severity UNKNOWN). UNKNOWN retains active boolean for active-alert metrics.
6. Output each event: state, active, severity, reason. For invalid evidence reason is its validity code; for valid output with reset reason use reset; otherwise valid suppressed active output reason SUPPRESSION; otherwise reason STATE. Trace agreement compares (state,active,severity) sequence. Reason agreement is secondary and reports deterministic policy reasons; it is not inferred industrial root cause.

## Distinctness
Paper 6 addresses definition–implementation discrepancies within artifacts. This study consumes Boolean review findings and evaluates versioned event sequences. It does not modify the discrepancy detector, estimate legal compliance, or improve lexical finding accuracy. The evidence binding mechanism is compared against identical temporal processing with binding removed. Timer-only monitoring is an explicit baseline. Existing LEAP runs per source snapshot as a separate descriptive baseline without a claimed temporal contract.

## Pre-implementation clarification (before oracle and benchmark freeze)
SUPPRESSED severity is NONE; underlying escalation clock is retained. All four policy durations must be finite nonnegative numbers. Required event fields t/unit/c/p must exist; unit is s or ms, c/p are nonempty strings. Timestamp must be finite. Observations, if supplied, require value (strict Boolean or null), c/p (nonempty strings), at (finite number). Suppression, if supplied, requires c/p (nonempty strings) and until (finite). Malformed records raise ValueError. No observation at a time between supplied events is assumed; decisions are made only on recorded events. Timer continuity across successive valid observations is the study's sample-and-hold contract. Metadata changes alone have no semantic effect.
