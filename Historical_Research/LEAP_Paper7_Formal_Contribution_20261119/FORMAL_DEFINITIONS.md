# Formal definitions and scope

## Source objects

Let `S` be the domain of readable, extraction-valid source snapshots in the archived file types, with a fixed extractor version, configuration and deterministic environment. A source revision is an ordered pair `(s_before,s_after)` in `S²`. The archive has nine such pairs, `P7R01`–`P7R09`. Comparisons below are equality comparisons of **recorded representations**; they are not claims of semantic equivalence. SHA-256 identifiers are treated as the observed equality tokens, not as a mathematical proof that distinct underlying objects cannot collide.

`C:S→CVal` is the executable-structure signature recorded by `run_experiment.py:fingerprint` (lines 37–54): for Python, SHA-256 of `ast.dump(ast.parse(text), include_attributes=False)`; for SQL/TSQL, SHA-256 of canonical comment-stripped and case-normalized tokens; for ABAP, the analogous comment-stripped token screen. `D:S→DVal` is the SHA-256 signature of sorted, canonical LEAP-generated candidate rows from `run_experiment.py:dossier` (lines 56–65). Each row has the candidate name and eight selected detail fields: description, objective, formula_description, used_in_kpis, input_measure, unit_of_measure, reporting_source and comments. The file-byte identity `H:S→HVal` is SHA-256 of the source bytes. The extraction pipeline is defined only for snapshots on which its required parsing/generation succeeds. `C` is structural and `D` is generated text; equality of either does not imply equal executable behavior, and inequality does not establish operational importance.

Define `δ_C(s,t)=1[C(s)≠C(t)]`, `δ_D(s,t)=1[D(s)≠D(t)]`, `δ_H(s,t)=1[H(s)≠H(t)]`, and `u=δ_C∨δ_D`. The archived classes are `00:{P7R06,P7R08}`, `01:{P7R01,P7R02,P7R04,P7R05}`, `10:{P7R09}`, `11:{P7R03,P7R07}`. All nine have `δ_H=1`. These are pair observations, not nine independent operational monitoring histories.

## Binding and histories

An admissible source-to-evidence binding is a deterministic function `b:S→K` that maps each source snapshot to a nonempty opaque evidence identity, using the same extraction environment throughout a history. Its equality relation `s∼_b t ⇔ b(s)=b(t)` determines whether the monitor sees a context change. The four frozen bindings are `b_H(s)=H(s)`, `b_C(s)=C(s)`, `b_D(s)=D(s)`, and `b_CD(s)=canonical_json([C(s),D(s)])`. Thus `b_CD(s)=b_CD(t)` iff both signatures agree, while `b_C` and `b_D` equate snapshots by their respective single signatures. Separately, the transition projection `u(s_before,s_after)=δ_C∨δ_D` reports one reset signal for a specified pair. It is not a binding `S→K` and cannot serve as a persistent global version identity. No theorem silently extends from `b_CD` to all bindings.

A valid monitoring history is a finite time-ordered sequence of events `e_1…e_n` with source snapshot `s_i`, current evidence identity `c_i=b(s_i)`, independent policy identity `p_i`, event time `t_i`, optional observation `o_i=(value,context,policy,at)`, optional deferral `z_i=(context,policy,until)`, policy durations `D,C,E,F`, base severity, and a specified initial monitor state. The archived execution uses the frozen empty initial state and strict time increase. Event times and packet times in `s` or `ms` are normalized to seconds. Required numeric values are finite; durations are nonnegative; version strings are nonempty; observation value is Boolean or `None` for conflict. Schema or time failures are outside the admissible history domain. An observation is usable only if present, both identities match current identities, value is Boolean, and `0≤t_i−at_i≤F`. A deferral applies only to an active episode when present, both identities match and `t_i<until_i`; equality at expiry is expired. No event is emitted between supplied times.

The deterministic frozen monitor first resets timers and activity on a current context or policy change, with `POLICY_CHANGE` taking reset-reason precedence when both change. It then validates the observation in this order: missing, context mismatch, policy mismatch, future, stale, conflict. An unresolved observation yields `UNKNOWN`, clears qualification/clearing runs, and retains any activity left after reset. Otherwise positive and negative samples update qualification/clearing; threshold equality counts. The display is then escalated or deferral-suppressed as specified in `frozen_monitor/Paper7_Reproduction/study/implementation/monitor.py`. An applicable deferral can hide display without clearing activity. The reason after a valid observation is reset reason, then `SUPPRESSION` if displayed, else `STATE`.

Let `M_q(h)` denote the deterministic output of the frozen monitor with fixed policy parameters `q`, and let `O_dec(h)` be the **entire event sequence** of `(displayed state, activity, severity)`; `O_full(h)` appends reason at every event. `O_dec^last` and `O_full^last` are the final-event values, defined only for nonempty histories. Sequence preservation implies final-event preservation on equal-length histories; the converse need not hold. The manuscript's 3/5/6 comparison propositions concern complete event sequences.

## Projection, policy class and equivalence

A reduced information projection `π` acts on complete valid histories. Every particular `π` states what it retains. The source-channel projections considered here retain event and observation times, packet presence and values, expiry, duration and severity parameters, policy identity and policy change, **the common initial monitor state**, and the chosen context-change and packet-context-match information; they hide source snapshots and raw opaque context names. Two histories are indistinguishable only when every retained side input and every retained comparison agrees. Raw hashes are treated as opaque equality tokens; a decoder supplied with a source/hash lookup table has a different, richer projection and is outside the restricted-strategy witness.

For complete unrestricted histories, the six-comparison interface retains per event `(current context changed, current policy changed, observation context match, observation policy match, deferral context match, deferral policy match)` when packets exist; the five-comparison interface joins the last two; the three-comparison interface retains `(joint current change, joint observation match, joint deferral match)`. All retain the non-version inputs and initial state above. These are temporal interface projections, distinct from the two source-pair change bits.

`P_fixed={q_0}` is the frozen transition and reason policy with the declared input contract. `P_contract` varies admissible nonnegative durations and severity while retaining that transition structure. `P_sep` is an explicit *comparison class*, not the frozen monitor: it contains two source-reset variants, one that resets on `δ_C` and one on `δ_D`, with otherwise identical transition rules. Its purpose is to test when separately distinguishable channels are necessary. Arbitrary source-sensitive policies outside this class can inspect source content not represented by `C,D`.

For a required output `O∈{O_dec,O_full,O_dec^last,O_full^last}` and declared class `P`, a projection preserves output iff `∀q∈P ∀h,h'∈H_q: π(h)=π(h') ⇒ O(M_q(h))=O(M_q(h'))`, with equal retained policy identity/parameters and initial state. The output kernel is the equivalence relation `h≈_{q,O}h'` iff their required outputs agree; for a policy class it is the intersection of these kernels on comparable side-input fibres. This is the exact output-relative meaning of a correct information partition.
