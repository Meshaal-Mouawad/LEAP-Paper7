# LEAP Paper 7 - Integrated source-to-alert manuscript

The primary manuscript is `Paper7.tex`. Run `sh build.sh` with a LaTeX installation (pdflatex, bibtex8 or bibtex), or use the bundled resolved bibliography `Paper7.bbl` when the bibliography tool is missing.
