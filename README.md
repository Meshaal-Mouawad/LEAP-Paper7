# LEAP Paper 7 — complete submission and reproduction package

This repository preserves the complete JSS submission package and its
reproducibility materials.

- `Submission/01_UPLOAD_TO_JSS/`: manuscript, LaTeX source, highlights,
  cover letter, and the three reproduction ZIP files.
- `Submission/02_COPY_PASTE_FIELDS/`: journal submission metadata.
- `Submission/03_VERIFICATION/`: checksums and verification records.
- `Submission/START_HERE.txt`: original JSS upload instructions.
- `Original_Archive/`: unchanged complete original submission ZIP.
- `Harvard_Dataverse_Archives/`: optional copies of the two Harvard deposit
  ZIP files if they were available locally when the script ran.

Harvard Dataverse dataset DOI: https://doi.org/10.7910/DVN/3A5J9E

The GitHub repository is initially private. The Harvard dataset may still
be under repository review; its publication status is managed separately.
